# NEXUS

NEXUS 是一款正在规划中的 **2D 叙事生存射击游戏**。项目由小型团队协作开发，暂定使用 Godot 4。

> 当前阶段：项目初始化 / 原型准备。核心玩法、世界观细节和美术规范仍在讨论中。

## 项目目标

先完成一个小规模、可反复游玩的垂直切片（Vertical Slice），验证移动、瞄准、射击、敌人、拾取物品和剧情触发等核心体验，再逐步扩展地图与内容。

## 技术栈

- **引擎：** Godot 4
- **脚本：** GDScript
- **版本管理：** Git / GitHub
- **目标类型：** 2D 生存射击 + 叙事探索
- **视角：** 暂定俯视角，最终方案待团队确认

## 仓库结构

```text
NEXUS/
├── Game/                 # Godot 游戏工程
│   ├── scenes/           # 场景
│   └── scripts/          # GDScript 脚本
├── Docs/                 # 设计与开发文档
│   ├── Story/            # 世界观、角色、任务与剧情
│   └── Systems/          # 战斗、物品、敌人等系统设计
├── Assets/               # 美术、音频与其他游戏资源
├── Tests/                # 测试计划与测试记录
├── .gitignore
├── CONTRIBUTING.md
└── README.md
```

## 快速开始

1. 安装 Godot 4（建议团队统一使用同一个稳定版本）。
2. 克隆本仓库。
3. 在 Godot Project Manager 中导入 `Game/project.godot`。
4. 运行项目，当前入口场景为 `Game/scenes/main.tscn`。

## 开发原则

- 先做可玩的最小原型，再扩展系统。
- 核心系统尽量模块化，避免所有逻辑堆在单个脚本中。
- 设计决策记录在 `Docs/`，不要只留在聊天记录里。
- 美术资源统一命名、尺寸、锚点和导入规范。
- 通过分支和 Pull Request 协作，避免直接覆盖他人工作。
