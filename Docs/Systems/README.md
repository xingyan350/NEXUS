# 系统设计

每个系统建议使用独立文档描述：目标、玩家操作、状态、规则、边界情况、与其他系统的接口和验收标准。

建议优先级：

1. `player.md`：移动、瞄准、受击、交互
2. `combat.md`：武器、射击、弹药、伤害
3. `enemies.md`：敌人状态机、感知、导航与攻击
4. `items_inventory.md`：拾取、物品数据、背包
5. `interaction.md`：调查、门、容器和场景触发
6. `narrative.md`：对话、任务、剧情条件和状态
7. `save_load.md`：存档数据与版本兼容

## 系统文档模板

- 目的与体验目标
- 玩家输入
- 状态与数据
- 规则与流程
- 异常 / 边界情况
- 与其他系统的接口
- 验收标准
- 未决问题
