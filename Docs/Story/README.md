# 剧情与世界观

本目录用于保存经过团队讨论的正式设定。

建议逐步建立：

- `world.md`：世界观、历史、地理与关键事件
- `characters.md`：角色档案、关系与人物弧光
- `timeline.md`：时间线与事件因果
- `missions/`：任务流程、触发条件、目标与结果
- `dialogue/`：对白、分支与条件

## 写作约定

- 区分“已确定设定”“候选方案”和“待讨论问题”。
- 重要事件记录时间、地点、参与者、原因和后果。
- 分支剧情明确写出触发条件与状态变化。
- 避免只记录对白；同时记录玩家能看到、听到和操作的内容。

目前尚未写入具体世界观或剧情，以免在团队尚未确认前锁定创作方向。
