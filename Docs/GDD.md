# NEXUS — 游戏设计总纲（GDD）

> 文档状态：初稿 / 待团队讨论  
> 本文记录当前方向与待决策事项，不代表所有设计已经定案。

## 1. 游戏概述

- **类型：** 2D 生存射击、探索与叙事
- **参考方向：** 以俯视角生存射击为基础，结合环境叙事、角色关系和任务剧情
- **玩家人数：** 暂定单人体验
- **引擎：** Godot 4
- **目标平台：** 待定

## 2. 核心体验目标

1. 在危险区域中探索并管理有限资源。
2. 使用枪械应对敌人与环境威胁。
3. 通过地点、物品、记录和 NPC 对话了解故事。
4. 让玩家的选择对任务走向或角色关系产生影响。

## 3. 核心循环（待验证）

进入区域 → 探索与搜集 → 遭遇威胁 → 战斗或规避 → 带回资源与信息 → 推进剧情 / 准备下一次行动。

## 4. 候选系统

- 玩家移动、瞄准与交互
- 武器、弹药、装填与伤害
- 敌人感知、追踪与攻击
- 生命值、状态与资源管理
- 物品拾取、背包与使用
- 地图、区域入口与关卡事件
- 对话、任务、日志与剧情触发
- 存档与设置

系统优先级需要通过首个 Demo 验证后再调整。

## 5. 美术与音频方向

整体风格尚待团队确定。需要尽早统一：
- 角色与敌人的像素尺寸 / 分辨率
- 角色朝向、动画帧数与动画状态
- 地图网格、碰撞体和排序规则
- UI 视觉规范
- 环境音、武器音效和音乐的授权来源

## 6. 首个可玩 Demo 范围

建议只制作一个小区域，包含：
- 一个可操作角色
- 一种基础枪械
- 一种敌人
- 一种可拾取物品
- 一个简单交互点
- 一段短剧情触发
- 一个明确的开始与结束条件

暂不纳入多人联机、大型开放世界、复杂基地建造和大量武器改装。

## 7. 待团队确认

- 最终采用纯俯视角还是斜俯视角
- 像素风、手绘还是其他 2D 风格
- 是否有安全屋 / 据点循环
- 战斗偏动作射击还是偏战术资源管理
- 是否采用任务制地图
- 剧情分支对玩法和结局的影响
- 目标平台与输入方式
